> *«Можно делегировать мышление, но нельзя делегировать понимание»*  
> — Фундаментальный принцип агентной инженерии (Software 3.0)

**dsh-vibecoding 3.0** — автономный фреймворк агентной инженерии для [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness). Плагин переводит разработку со слепого вайбкодинга («работает — не трогай») в дисциплину системной инженерии (Agentic Engineering), устраняя аномалии «зубчатого интеллекта» с помощью жестких программных ограничений (Guardrails), долговременной памяти и автоматов защиты от зацикливания.

Включает интерактивный **Web HUD** с индикатором Стриков (0..3), кнопкой мгновенного отката (**Panic Rollback**) и кнопкой фиксации памяти (**Session Wrap-up**) прямо в панели ввода DSH!

1. 📄 **Spec Gatekeeper & Правило 90% уверенности (`lib/spec.js`):**  
   Физическая блокировка инструментов модификации кода до тех пор, пока не создан и утвержден контракт `scope.md`. Если уверенность в схеме БД или контрактах ниже 90%, агент обязан задать вопрос пользователю.
2. 🎯 **Brownfield Scope Lock (Защита легаси-кода):**  
   Для каждого атомарного шага в `scope.md` задается список целевых файлов `Target Files: [src/auth.js]`. Попытки модификации смежных модулей блокируются плагином на корню.
3. 🛑 **Автомат «3-Strike Rule» против зацикливания (`lib/strikes.js`):**  
   * **Strike 1:** Автогенерация 3-компонентного отчета об ошибке.
   * **Strike 2:** Программный запрет на изменение кода! Агент обязан провести Root Cause Analysis (RCA) с 3 альтернативами и триггером `ultrathink`.
   * **Strike 3:** Автоматический откат `git reset --hard HEAD` к последнему чекпоинту, запись ошибки в `Failed Approaches` и рекомендация сброса контекста (`/clear`).
4. 🧠 **Compound Engineering & Долговременная память (`lib/memory.js`):**  
   Автоматическое ведение `.dsh/memory/memory.md` (Executive Summary, Milestones, Failed Approaches, Tech Debt) и ротация памяти при забивании контекстного окна.
5. 👂 **Live Server Daemon — «Слушай сервер» (`lib/server.js`):**  
   Фоновый запуск веб-серверов (Node.js, Next.js, Vite, FastAPI) со стримингом логов `stdout`/`stderr` в кольцевой буфер и мгновенным отловом крашей до сдачи работы пользователю.
6. 🛡️ **Pre-Commit Bugbot & Anti-MenuGen Guard (`lib/security.js`):**  
   Сканирование диффов перед коммитом: отлов утечек приватных ключей, аудит `.gitignore`, проверка SQL-инъекций и защита от багов MenuGen (запрет привязки платежей по строке `email` без persistent `user_id`).
7. 🚀 **Zero DevOps Bottleneck (`lib/devops.js`):**  
   Генерация производственного комплекта деплоя за один клик (Nginx reverse proxy, бесплатный SSL Let's Encrypt, Systemd сервис, Dockerfile и setup.sh под Ubuntu / TimeWeb VPS / Amvera).
8. 🔀 **Git Save Points & Чистый Squash (`lib/worktree.js`):**  
   Автоматический сквош цепочки микро-коммитов в чистый атомарный коммит перед слиянием в `HEAD`.

## 🛠️ Инструментарий плагина в `ctx.tools`

| Инструмент | Описание |
| :--- | :--- |
| `scope_manage` | Управление контрактом `scope.md` (инициализация, статус, продвижение шагов `- [ ]` $\to$ `- [x]`). |
| `memory_manage` | Управление долговременной памятью `.dsh/memory/memory.md`, запись вех, техдолга и Wrap-up. |
| `strike_guard` | Проверка счетчика зацикливаний и снятие блокировки Strike 2 через подачу Root Cause Analysis (RCA). |
| `server_daemon` | Запуск, остановка, проверка статуса и чтение живых логов фоновых dev-серверов. |
| `devops_provision` | Генерация полного production-комплекта деплоя (Nginx, SSL, Systemd, Docker, setup.sh). |
| `run_tdd_cycle` | Запуск тестов проекта с автоматическим контролем 3-Strike Rule и Save Point на GREEN. |
| `verify_deliverable` | Смоук-тест в Headless Chrome + статический аудит Bugbot (секреты, Anti-MenuGen, SQLi). |
| `complete_interview` | Гейткипер Фазы 1 с валидацией контракта `scope.md` для сложных систем (Tier 2). |
| `create_worker_brief` | Генерация сверхкомпактного lean-промпта для параллельных воркеров (-80% токенов). |
| `worktree_create` | Создание изолированного git worktree в `.worktrees/<name>` с потокобезопасной блокировкой. |
| `worktree_merge` | Слияние ветки воркера в `HEAD` с автоматическим сквошем (`squash: true`). |
| `worktree_remove` | Безопасная очистка worktree с сохранением незакоммиченного кода в ветке. |
| `worktree_list` | Список всех активных изолированных воркдеревьев. |
| `checkpoint_create` | Создание легковесного снимка дерева (`commit-tree` tag) без загрязнения рабочего каталога. |
| `checkpoint_restore` | Атомарный откат к контрольной точке через `read-tree` с бэкапом незакоммиченных файлов. |

## 🖥️ Web HUD в панели ввода DSH

Плагин монтирует интерактивную кнопку волны в правый угол панели ввода сообщений DSH:
* **Индикатор состояния:** светится градиентом в активном режиме, желтым при 1 ошибке, мигает красным при блокировке Strike 2.
* **Интерактивный Popover:**
  * Текущий счетчик Стриков (`0/3`, `1/3`, `2/3 RCA 🔒`).
  * Статус `scope.md` и активного шага.
  * Статус памяти `.dsh/memory/memory.md`.
* **Кнопка `↺ Rollback`:** мгновенный откат к последнему стабильному чекпоинту без набора текста в чат!
* **Кнопка `📦 Wrap-up`:** немедленная фиксация архитектурного статуса сессии в долгосрочной памяти.
