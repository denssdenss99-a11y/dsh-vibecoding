**dsh-vibecoding 2.1** — адаптивный бережливый мульти-агентный оркестратор для [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness). 

Сочетает скорость гибкого вайбкодинга со строгой программной инженерией: **Contract-First декомпозиция**, параллельные субагенты в изолированных **Git Worktrees** (с авто-инициализацией), динамические уровни сложности (**Complexity Tiering**), защита от перерасхода токенов (**Anti-Chat-Dump Token Saver**), инвариант **Zero Dead Code**, кнопочный переключатель прямо в панели ввода DSH Web GUI и автоматический смоук-тест в изолированном Headless Chrome.

---

## ⚡ Архитектура Vibecoding 2.1: Адаптивность, Экономичность и Масштаб

1. 🚀 **Smart Fast-Path (Умный гейткипер):** Если запрос уже содержит ясные требования или слова *«придумай сам» / «сделай»*, агент **не задает лишних бюрократических вопросов**, а мгновенно разблокирует выполнение (`comprehensive_prompt` / `creative_freedom`), экономя ходы диалога и десятки тысяч токенов.
2. 📄 **Адаптивные уровни сложности (Complexity Tiering):**
   * **🟢 Tier 1 (Компоненты / Демо / Скрипты):** Без лишних Markdown-спецификаций на диске, прямое создание модульного кода (`index.html`, `style.css`, `src/`), минимизация вызовов `todo_write`.
   * **🔵 Tier 2 (Сложные системы / Full-stack):** Обязательный единый источник истины (`docs/architecture.md`), контракты API, схемы данных и веховый (Milestone) трекинг в `todo_write`.
   * **🚀 Архитектурный лифт (Escalation on Demand):** Плавный промоушен проекта при разрастании (прототип $\to$ продакшен) без потери контекста.
3. 📦 **Contract-First Multi-Agent Swarm (Параллельный веер):**
   * В проектах с несколькими подсистемами лид-агент обязан **первым шагом** зафиксировать спецификацию контрактов (`docs/contracts.md` или `schemas.py`) с форматами данных и эндпоинтами.
   * Независимые модули делегируются **параллельным субагентам** через компактные брифы (`create_worker_brief`) в изолированных ветках, сокращая время разработки в 3–4 раза.
4. 🌱 **Auto-Init Git Worktrees:**
   * При создании воркдеревьев (`worktree_create`) плагин автоматически инициализирует Git-репозиторий (`autoInit`), даже если проект открыт в чистой папке без `.git`. Субагенты получают изолированные каталоги без риска перезаписи файлов.
5. 🛑 **Anti-Chat-Dump Mandate & Token Saver:**
   * Строгий запрет на дублирование мегабайтов кода в окно чата после сохранения на диск (даже если пользователь буквально просит *«выведи код в блоке html»*).
   * Код доставляется записью на диск, а агент сразу вызывает `present`, проводит верификацию и отдает компактное резюме Senior Engineer, исключая остановки на вопросах *«и что?»*.
6. 🧪 **Пакетная диагностика (Batch Probing) и инвариант «Zero Dead Code»:**
   * Запрет на спам одиночными вызовами bash (`python3 -c "import X"`). Проверка всех библиотек выполняется в 1 пакетную команду.
   * Каждый созданный файл обязан импортироваться в точке входа. Заброшенные файлы в `src/` блокируются валидатором.
7. 🎯 **Прагматичная верификация (Без фиктивного TDD):**
   * Строгий запрет на «театр TDD» (тесты строк `assert(html.includes('three'))`).
   * Для алгоритмов и бэкенда — реальные юнит-тесты на граничные случаи через `run_tdd_cycle`.
   * Для UI, графики и песочниц — автоматический запуск в изолированном Headless Chrome (`verify_deliverable`) с проверкой отсутствия ошибок консоли, синтаксиса и WebGL-рендеринга.
8. 🌟 **Product Excellence Boosters:**
   * **Веб-виджеты:** адаптивные модальные окна, embed-код с `<iframe>` для Tilda/WordPress/Webflow, стеклянный HUD, управление Web Audio по жесту.
   * **Физические симуляции (Matter.js / Canvas):** кинематический раскол тел через локальную матрицу поворота, дифференциация материалов (хрупкое стекло со звоном, прочный камень, цепная детонация TNT), арсенал взаимодействия (рогатка с пунктирной дугой баллистики, тяжелая пушка, взрывная волна).

## 🖥️ UI Кнопка в DSH Web

Плагин регистрирует кнопку с иконкой волны **`⚡ Vibe Harvester`** в панели ввода сообщений DSH:
* **Тихий режим:** переключает режим на лету через локальный API без вставки лишнего текста в поле ввода.
* **Подсветка:** светится градиентным неоновым цветом в активном состоянии.
* **Подсказка:** при наведении мыши или фокусе отображает интерактивное окно с текущим статусом оркестратора.

## 🛠️ Инструменты плагина для агента

Плагин регистрирует 10 специализированных инструментов в `ctx.tools`:

| Инструмент | Описание |
| :--- | :--- |
| `complete_interview` | Разблокирует Фазы 2–5 (Gatekeeper) после фиксации требований. При сложности `L`/`XL` автоматически направляет в параллельный swarm-режим. |
| `create_worker_brief` | Генерирует супер-компактный lean-промпт для субагентов (экономия до 80% токенов в основном контексте). |
| `run_tdd_cycle` | Запускает тесты проекта (`npm test`, `pytest`, `cargo test`, `make`, `dotnet`) и возвращает статус со стектрейсом. |
| `worktree_create` | Создает изолированный git worktree в `.worktrees/<name>` с новой веткой. Поддерживает `autoInit` для работы в чистых папках без Git. |
| `worktree_list` | Показывает список всех активных изолированных воркдеревьев. |
| `worktree_merge` | Сливает выполненную ветку воркера обратно в текущий `HEAD`. |
| `worktree_remove` | Безопасно очищает worktree после слияния (автоматически сохраняет незакоммиченный код воркера в ветку). |
| `verify_deliverable` | Автоматический смоук-тест: проверяет синтаксис JS/HTML без опасного исполнения (`node --check`, `vm.Script`), внешние зависимости и рендеринг в изолированном Headless Chrome. |
| `checkpoint_create` | Создает изолированный снимок дерева репозитория (GIT_INDEX_FILE + commit-tree tag) без модификации рабочей копии и без засорения `git stash`. |
| `checkpoint_restore` | Атомарный откат к контрольной точке через `git read-tree --reset -u` (предварительно сохраняет незакоммиченные файлы в `git stash`). |

## 🛡️ Безопасность и Safe Mutate Guard

1. **Safe Mutate Guard:** запрещено молча удалять файлы, блоки или сущности. Любые деструктивные действия требуют предварительного подтверждения пользователя на русском языке.
2. **Защита данных при очистке:** `worktree_remove` и `checkpoint_restore` никогда не сносят несохраненный код — все промежуточные изменения автоматически фиксируются в ветках или `git stash`.
3. **Безопасная проверка синтаксиса:** встроенные скрипты HTML проверяются через AST-компилятор Node.js `vm.Script` без физического запуска кода в системе.
4. **Защита от выхода за пределы проекта:** вызовы инструментов ограничены корнем репозитория (`path traversal guard`).
5. **Строгая валидация Loopback Origin:** защита WebServer API от DNS-rebinding и CSRF атак через проверку протоколов (`http:`, `https:`) и локальных хостов.

## ⚙️ Настройка моделей (Оркестратор vs Воркеры)

В файле `~/.dsh/profiles/web/cordis.patch.yml`:

```yaml
# Оркестратор сессии (умная модель):
- id: agent-default-model
  name: "@deepseek-ai/dsh-agent-default-model"
  config:
    provider: gemini-oauth
    model: gemini-3.1-pro
    reasoningEffort: high

# Для воркеров (субагентов subagent) агент автоматически задействует быстрые модели (gemini-3.8-flash)
```
